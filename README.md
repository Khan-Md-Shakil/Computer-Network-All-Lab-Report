# Computer Network - All Lab Reports

A comprehensive collection of all laboratory reports for the Computer Network course. This repository serves as a complete reference guide for students and learners to understand practical networking concepts, configurations, and analysis.

## Lab Topics Covered
- Network Topologies (Star, Bus, Ring, Mesh)
- IP Addressing and Subnetting
- Routing Protocols (Static & Dynamic)
- Switching and VLAN Configuration
- Network Devices (Router, Switch, Hub)
- Protocol Analysis using Wireshark
- Network Troubleshooting and Testing
- Cisco Packet Tracer Simulations

## Tools & Technologies
- **Simulation:** Cisco Packet Tracer
- **Analysis:** Wireshark
- **Environment:** Windows / Linux

## Repository Structure
Each lab report includes:
- **Objective:** Purpose of the experiment.
- **Procedure:** Step-by-step instructions.
- **Configuration/Code:** Commands and settings used.
- **Screenshots:** Visual proof of results.
- **Conclusion:** Summary of the experiment.

## How to Use
1. Browse the folders to find the specific lab report you need.
2. Open the PDF/Word documents to view detailed procedures and results.
3. Use the configurations as a reference for your own practice.
